Namebound Privacy Policy

Last updated: 11 October 2026

Namebound is a game for Android made by Daddy-Ousen ("we"). This page tells you what data the game uses.

Short version

Namebound does not collect, send or sell any personal data. The game works offline. It has no account, no login and no ads.

What the game keeps on your phone

The game saves your progress in a file on your phone. This file holds things like gold, cleared stages, gear, settings and quest progress. The file stays on your phone. We cannot see it. If you uninstall the game, Android deletes the file.

Internet

The game downloads one small public file (a list of weekly challenges and monthly events) from this site. It saves a copy on your phone and works offline without it. The game sends no data about you with this request. Like any web request, the host (GitHub Pages) can see your IP address. We do not receive or store it. The game sends no other data to us or to any other company.

Permissions

The game asks Android for two permissions. Vibrate: it shakes the phone when your hero gets hit or levels up (you can turn this off in Settings). Internet: it downloads the events file described above.

Google Play

You get the game from Google Play. Google can collect data about the install and the download under its own privacy policy: policies.google.com/privacy. We only see the summary reports that Google gives to all app makers.

Children

The game is made for players aged 13 and up. We do not knowingly collect data from anyone, of any age.

Changes

If a future version adds something that uses data (for example ads, purchases or cloud saves), we will update this page before that version comes out. The date at the top shows the last change.
